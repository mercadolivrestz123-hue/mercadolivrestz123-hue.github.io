Letrado

Jogo de palavras Grátis · sem cadastro · celular e PC
Abrir só o jogo

Letrado é um jogo de palavras em português. Você tem seis tentativas para descobrir uma palavra de cinco letras, e as cores de cada palpite mostram o quanto você chegou perto. Diferente de jogos com uma palavra por dia, aqui as rodadas são infinitas.

Como jogar Letrado

  1. Digite uma palavra de 5 letras e confirme.
  2. Verde: a letra está certa e no lugar certo.
  3. Amarelo: a letra existe na palavra, mas em outra posição.
  4. Cinza: a letra não está na palavra. Acentos não contam.
  5. Você pode usar uma DICA por rodada para revelar uma letra.

Controles

Use o teclado da tela ou o teclado do computador. Enter confirma e a tecla de apagar corrige.

Dicas

  • Comece com uma palavra que tenha várias vogais diferentes, como SERIA.
  • Não repita letras cinzas: cada palpite deve testar letras novas.
  • Use as amarelas em posições diferentes para descobrir onde ficam.
  • Guarde a DICA para a quinta ou sexta tentativa.

Quer ir mais longe? Leia Estratégias para o Letrado.

Perguntas frequentes

Letrado é igual ao Termo ou Wordle?
É do mesmo estilo de adivinhar palavras, mas com rodadas infinitas, dica e lista própria de palavras.
Precisa colocar acento?
Não. As palavras são escritas sem acentos.
Minhas estatísticas ficam salvas?
Sim, no seu navegador: jogos, porcentagem de vitórias e sequência.
