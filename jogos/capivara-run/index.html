Capivara Run

Corrida infinita Grátis · sem cadastro · celular e PC
Abrir só o jogo

Capivara Run é uma corrida infinita com a capivara mais tranquila do Brasil. Ela corre sozinha e você só precisa pular na hora certa para passar pelos obstáculos e pegar as laranjas pelo caminho.

Como jogar Capivara Run

  1. Toque ou aperte espaço para pular.
  2. Segure para pular mais alto.
  3. Toque de novo no ar para dar o pulo duplo.
  4. Colete laranjas e vá o mais longe possível. A velocidade aumenta com a distância.

Controles

Celular: toque. Computador: espaço, seta para cima ou clique.

Dicas

  • Pule um pouco antes do obstáculo, não em cima dele.
  • Guarde o pulo duplo para corrigir um pulo curto.
  • Pulos longos servem para obstáculos em sequência.
  • Não persiga toda laranja: a distância vale mais.

Perguntas frequentes

Capivara Run é grátis?
Sim, grátis e sem cadastro.
Tem fim?
Não, é uma corrida infinita. O objetivo é o recorde de distância.
Funciona no PC?
Sim, com espaço ou seta para cima.
